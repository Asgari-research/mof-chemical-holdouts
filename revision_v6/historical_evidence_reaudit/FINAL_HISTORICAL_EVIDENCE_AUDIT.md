## Numerical reconciliation and required corrections

- **No historical numerical contradiction** was found for the frozen V6 random/topology shortlist (all eight compared counts/metrics match), the original CO₂ 0.15-bar exact topology-family table (47 groups, 263,744 rows, MAE/bias differences ≤2.3×10⁻¹⁶), the saved original fold metrics, or the geometry-group size and fold counts. The original topology aggregate archive matches recovered topology predictions to maximum absolute difference 8.9×10⁻¹⁶ mmol/g.
- **Material evidence-availability correction:** `V6_AdvancedScience/reports/SCIENCE_FREEZE.md`, `final_reviewer_computation/FINAL_REVIEWER_EVIDENCE.md`, `RUN_SUMMARY.md`, and related draft response/PR text state that original random repeat rows and paired cross-pressure MOF rows were unavailable. That statement was true for the earlier local inventory but is **false after these archives were recovered**. Replace it in any future manuscript/SI/response integration; prior files were deliberately left untouched. The R2.1 paragraph in the earlier `FINAL_REVIEWER_EVIDENCE.md` should cite the recovered original-row calculation above as primary, not claim only new-fit sensitivity.
- **Sampled-to-full correction:** earlier four-target family comparisons used a small sampled table (up to 500 per label, sometimes far less). The exact original 263,744-row target files now provide full-family estimates. Use `results/pressure_family_exact.csv` and `results/pressure_family_rank_summary.csv` for claims; keep the earlier sampled table clearly marked historical context, not an equivalent estimate. For example `sqc` CO₂ 0.015-bar MAE/IQR changes from sampled 2.514 (n=22) to full 3.298 (n=1,787). The broad observation that `fsc` is difficult at lower pressures survives, but full-family ranks and matched-MOF persistence are more precise.
- **Geometry provenance boundary remains:** recovery establishes that `geo-clusters.csv` was the exact label source. Its own columns are `filename`, `cluster_id`, and `Database`; the recovered code imports labels rather than generating them. A targeted search of the recovered Python, logs, JSON and text metadata found no upstream clustering algorithm, distance metric, feature set or threshold. The model's `compact_geometry` and `enriched_interpretable` descriptor lists are **prediction features**, not evidence of how `cluster_id` was produced. No defensible numeric distance threshold can be stated.
- The existing V6 RAC-control findings, including adverse `pts` and `rna` results at both CO₂ pressures, were outside this audit and are **not contradicted or replaced**. The original per-MOF pressure comparison does not establish a causal pressure mechanism, and the original random-vs-topology comparison remains descriptive because one random value may average 1–5 OOS predictions whereas topology contributes one.

## Definitions, source paths and verification

`filename_norm` uses the executed pipeline's string replacement of `.cif` followed by trimming. Original `residual` is **truth − prediction**, so a positive mean indicates underprediction. All original prediction IDs are unique within a fold; topology predictions are unique across five folds. Target values and topology labels in the recovered rows match the processed master one-to-one. No topology label crosses folds, and identical topology-fold assignments are present in all four targets. For shortlist/recovery, k=ceil(0.05×177,411)=8,871, ranking uses descending prediction or true uptake with ascending normalized ID for ties. For high-error persistence, k=ceil(0.10×263,744)=26,375 per target. A target-wide IQR is Q75−Q25 over all 263,744 *true uptake* values, then each MOF's absolute error or family MAE is divided by that target's one fixed IQR; this makes cross-target scales explicit. Five one-prediction draws use seeds 20260–20264 and only original observed random OOS rows, with all singleton MOFs retained. Full source path and SHA256 for every recovered file are in `results/recovered_file_checksums.csv`; the two source ZIP hashes are in `results/source_archive_sha256.csv`.

The essential compact tables are `results/geometry_group_summary.json`, `geometry_group_size_distribution.csv`, `geometry_fold_integrity.csv`, `original_random_multiplicity.csv`, `original_random_archive_reconciliation.csv`, `original_random_sampling_sensitivity.csv`, `original_random_topology_shortlist.csv`, `original_sampling_vs_topology_shortlist.csv`, `pressure_target_iqr_exact.csv`, `pressure_family_exact.csv`, `pressure_family_rank_summary.csv`, `pressure_pairwise_error_persistence.csv`, `within_family_pressure_persistence.csv`, and `v6_shortlist_reconciliation.csv`. Additional compact reconciliation tables in the same directory retain exact fold/sample checks. The analysis is reproduced by `scripts/audit_original_predictions.py`; `tests/test_audit_outputs.py` passed **4/4** focused test cases. No original source archive or historical prediction row was rewritten. No new RF fit was performed.
